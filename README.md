# Powers 2048

A 2048-style game for learning powers (indices) with any base from 2 to 5.
Merge as many identical tiles as the base (e.g. three 3² tiles → 3³); every merge shows the calculation.

Play: https://lukasbiel.github.io/Powers/

URL options: `?base=2..5&size=4..7&mode=pow|val|both&lang=en|pl`
